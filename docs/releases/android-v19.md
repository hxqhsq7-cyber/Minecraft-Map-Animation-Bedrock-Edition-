# 方映 MapCinema Android v19

下载 `MapCinema-Android-v19.apk`。包名 `dev.mapcinema.offline`、versionCode 5，沿用此前发布签名，要求 Android 8.0+ 与较新的 WebView。

上空提前加载上限提高到 200 帧，每排 5 幅完整画面，依次向上堆叠。新视频、合并和“仅用旧世界升级（无需视频包）”均支持设置。默认关闭，起始高度仍可选上方 8–64 格；实际墙体可超出作为迁移依据的 16×16 区块，需足够空气区与维度高度。

共用电脑版分批创建、分批清理和已创建墙体的持久记录，兼容旧版预加载墙。8×4 屏幕提前 200 帧会增加 6400 个展示框，可能增加卡顿；超过维度高度时跳过，建筑和未加载位置暂缓。短片按实际帧数建立墙。

共享核心、设置上限、文件保存协议、APK 对齐、资源与发布签名校验通过；官方引擎检查包含 200 幅堆叠布局与清理。没有连接 Android 真机或游戏客户端，尚未验收手机安装和实际提前渲染效果。已有世界需先停止播放、导出并升级副本后再导入，单独更新 APK 不会修改存档。
