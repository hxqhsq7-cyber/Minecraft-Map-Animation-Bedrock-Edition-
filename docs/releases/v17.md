# 方映 MapCinema v17

新增可选的“上空提前加载（实验性）”，Windows 与 Android 共用同一套转换及播放生成核心。

- 自定义提前 1–8 帧、上方 8–64 格；默认关闭，启用默认提前 3 帧、上方 12 格。
- 临时墙固定在观看者当前 16×16 区块内；跨区块清理并迁移，同区块仍有观看者时保留共用墙。
- 复用原地图 ID，以环形墙轮换后续完整帧；循环读取下一轮开头，停止和结束自动清理。
- 无原视频包的旧世界也能在“仅用旧世界升级”中开启或关闭，无需重新抽帧。

下载 `MapCinema-v17-Windows-x64.zip`，完整解压后运行 `方映.exe`，保留旁边的运行文件。安卓版见独立的 `android-v17` 发布。软件不会自动更新已经导入游戏的世界，需要导出并导入升级副本。

开启预加载后需要基岩版 1.21.90+ 的稳定脚本 API，只在整组墙区域为空气且高度合法时创建。远距离传送导致旧区块卸载时，记录待清理位置，重新加载后补清理。请保持临时墙所在区域空闲。

实际打包 EXE 的转换和升级流程、导出包校验、预加载逻辑回归，以及官方 BDS 1.26.30.5 的 9 项结构放置和清理断言已通过。引擎测试使用模拟观看者，没有连接游戏客户端；不能据此保证头顶地图会被客户端提前绘制。额外地图墙刷新也可能增加卡顿，建议从较少帧数开始测试。完整长视频视觉验收与 Android 真机验收尚未完成。

Windows EXE 未配置 Authenticode 发布签名。附件校验值与构建清单供核对下载完整性。
