# 方映 MapCinema Android v16.1

下载 `MapCinema-Android-v16.1.apk` 安装。要求 Android 8.0 或以上和较新的 Android System WebView。

## 更新

- 将安卓版同步到 Windows v16.1 的共享转换与播放代码。
- 修复记分板名称导致“未找到 tick 功能”的函数加载问题。
- 更新为固定大小的播放时钟、地图复用与周期完整刷新。
- 增加“仅用旧世界升级（无需视频包）”入口。
- 支持所有同名盔甲架多屏同步，按每个播放点自己的水平朝向显示画面。
- 保留安卓系统文件选择、分块保存、保存后打开／导入及分享功能。
- 更新安卓提示和版本标识；补充按钮重播说明。

包名保持 `dev.mapcinema.offline`，内部版本号提高到 `2`，沿用此前 v15 APK 的签名证书，具备同签名覆盖升级条件。实际手机安装还未验收。

附件包含签名 APK、SHA-256 和包验证摘要。私钥、密码和构建工具不随仓库或发布附件上传。

已进行编译、签名、对齐、ZIP CRC、资源一致性、共享引擎同步及安卓保存桥接协议检查。当前没有连接的安卓设备，尚未完成手机安装、文件窗口操作、完整转换与 Minecraft 内播放验收。

大视频与音频仍受手机内存、存储、WebView 和游戏资源限制。请备份原世界，并保持转换在前台。
