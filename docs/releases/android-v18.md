# 方映 MapCinema Android v18

下载 `MapCinema-Android-v18.apk`。包名 `dev.mapcinema.offline`、versionCode 4，沿用此前发布签名，要求 Android 8.0+ 与较新的 WebView。

新增主页第 04 区域“地图动画 → 导出 MP4”：选择方映视频包或保留完整播放器的世界，恢复地图拼接和播放时序，输出 H.264 视频与可选 AAC 音轨。无需原视频，原存档只读，支持系统文件保存器分块写入及视频播放器打开／分享。

支持连续重复帧展开、增量地图、数据库日志和活动 SST 表；内存下载模式最高 256 MiB，建议直接保存。普通静态地图墙、丢失帧或像素的世界无法自动恢复视频。设备必须支持对应尺寸的系统 H.264 编码，AAC 缺少原生支持时使用内置离线备用编码器。

共享核心、文件保存协议、APK 对齐、资源与签名校验通过。Windows 的真实 MP4 导出和独立完整解码已验证；没有连接 Android 真机，尚未验证手机安装、系统文件选择与实际编码。AAC 可能存在少量头尾填充，清晰度受原地图数据限制。
