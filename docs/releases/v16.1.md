# 方映 MapCinema v16.1

将本地视频转换为 Minecraft 基岩版地图动画，支持固定坐标、同名盔甲架多屏同步、音轨、已有世界合并及旧播放器升级。

## 下载与运行

下载本发布附件中的 `方映-电脑版-v16.1-Windows-x64.zip`，完整解压后运行 `方映.exe`。保留旁边所有运行文件；GitHub 自动生成的 Source code 压缩包是源码，不是可直接运行的桌面软件。

本版为 Windows x64 便携版，无需另行安装 Python 或 Node.js。EXE 尚未配置 Authenticode 发布签名。附件同时提供 SHA-256 和构建文件清单。

## 本版内容

- 修复未加引号的 `#` 记分板名称导致基岩版拒绝加载播放函数的问题。
- 固定大小的播放时钟、分层帧调度、地图复用和周期完整刷新。
- 同名盔甲架同步播放，按各自水平朝向选择四个方向；提供新增播放点与朝向命令。
- 保留“仅用旧世界升级（无需视频包）”入口，升级操作输出世界副本。
- 补充按钮重播接法：使用独立脉冲命令方块执行完整播放命令；直接给播放时钟重新通电不会复位。
- 提供可独立克隆的源码与构建脚本，官方工具校验后缓存在项目目录。

## 验证与限制

已检查播放时序、旧世界升级、多盔甲架逻辑、实际 EXE 导出及发布文件完整性。官方基岩版服务端 1.26.30.5 的相关函数及短样例重播检查见仓库的 `docs/验证说明.md`。

整段视频的客户端画面、流畅度与音画同步仍需实际确认。屏幕规模、独立地图数量、播放点和区块加载都会影响表现；20 FPS 是目标设置，不保证所有设备均可达到。

所有转换在本机完成。此发布不包含个人世界或个人视频。
