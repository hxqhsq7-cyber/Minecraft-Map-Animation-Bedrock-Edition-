# 方映 MapCinema Android v17

下载 `MapCinema-Android-v17.apk`，要求 Android 8.0+ 及较新的系统 WebView。包名 `dev.mapcinema.offline`、versionCode 3，沿用此前 v15／v16.1 的发布签名。

新增与 Windows 共用的“上空提前加载（实验性）”：自定义 1–8 帧、上方 8–64 格，固定在观看者所在的 16×16 区块，跨区块迁移，同区块多人共用。新建视频和已有世界升级都能设置；无原视频包也可升级，输出世界副本。

默认关闭，开启需要基岩版 1.21.90+ 稳定脚本 API。临时墙仅在空气区创建，停止／结束后清理；旧区块卸载时待重新加载补清理。额外刷新可能增加卡顿，客户端提前渲染效果尚未验收。

共享引擎模块一致性、文件保存桥接、APK 对齐与资源校验、v1/v2/v3 签名以及原发布证书一致性已检查。官方 BDS 1.26.30.5 通过预加载结构放置与清理检查，观看者由测试模拟；未执行手机安装或 Minecraft 客户端长视频视觉验收。
