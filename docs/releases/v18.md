# 方映 MapCinema v18

新增主页第 04 区域“地图动画 → 导出 MP4”：读取方映 `.mcvideo` 或保留一个完整播放器的 `.mcworld`，按地图像素重新拼接为 H.264 视频，可合成现有音轨为 AAC，无需原视频或游戏录屏。

- 按原采样帧率和帧停留时间导出一轮，恢复增量帧和地图复用。
- 支持原始数据库日志及游戏整理后的活动 SST 表，校验地图像素与数据完整性。
- 直接逐帧保存，或在 256 MiB 内存额度内生成下载与预览；支持取消。
- Windows 与 Android 共用导出核心，旧版转换、盔甲架和区块预加载功能保留。

下载 `MapCinema-v18-Windows-x64.zip`，完整解压后运行 `方映.exe`。安卓版见 `android-v18` 发布。输出清晰度由地图数据决定，无法恢复原视频转换时损失的内容；普通静态地图墙缺少帧序列时不能恢复动画。

已通过真实 EXE 表单、视频包、日志世界、合成 SST 世界及官方 BDS 1.26.30.5 整理后的世界导出，独立 FFprobe/FFmpeg 核验与完整解码通过。另用本机旧世界完整恢复了 1024×512、20 FPS、1917 帧、95.85 秒的视频及现有音轨；个人世界和输出视频不上传。

视频轨保留原时序。AAC 重编码可能有少量头尾填充，部分播放器显示的容器时长会稍长；不承诺音轨逐样本无损或听感验收。Android APK 已签名校验，真机安装及编码仍需设备验收。Windows EXE 未配置 Authenticode 发布签名。

MP4 封装及 AAC 备用编码器的来源、许可和校验值见仓库 `THIRD_PARTY_NOTICES.md` 与 `tools/media-dependencies.json`。
