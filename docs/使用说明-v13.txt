方映 v13 · 大音频 / 固定坐标与命名盔甲架双模式

音频容量更新：
不再将安卓输入音频固定限制为 128 MiB。
“音频处理额度”默认 512 MiB，可选 128 / 256 / 512 / 1024 / 2048 / 4096 MiB，安卓与电脑相同。
新转换与合并补音轨都使用上方额度。额度分别检查输入文件与完整解码的音轨，不是保证可用的总内存；选择视频时按整个视频文件大小计算。
输出 WAV 最高 1024 MiB，且不超过所选额度。十分钟音轨约 27.5 MiB。
标准 PCM WAV 可分块读取选中片段，避免读取或解码整段源音轨，支持 PCM 8/16/24/32 位、float32、1–8 声道、8–192 kHz。
MP3/M4A/视频音轨仍需浏览器完整读取与解码；即使额度足够，浏览器可用内存不足也可能失败。可使用独立音频减少读取视频文件占用，或先截短音频。
WAV 分块路径仅源读取和临时采样缓冲按块使用内存，最终输出 WAV 仍保存在内存中。
大于旧版音轨上限的输出请用 v13 或更新工具合并。提高额度不会增加安卓浏览器实际可用内存。


两种定位方式都可用，默认固定坐标。

固定坐标：
1. “画面定位方式”选“固定坐标”，填写屏幕原点及方向。
2. 正常转换、合并世界、导入游戏，执行结果区的播放命令。
3. 画面放在所选坐标，竖向命令链放在 Z+6。可开启无损地图复用及静止块跳过。

命名盔甲架：
1. “画面定位方式”选“命名盔甲架”，填写名称，例如“方映屏幕”。
2. 设置画面相对盔甲架脚下方块格的 X/Y/Z 偏移，默认 0 / 2 / 0，即上方两格，避免覆盖实体。
3. 下方坐标改为命令链启动原点。命令链固定在该位置 Z+6，画面位置由盔甲架决定。
4. 转换 .mcvideo 后用本版加入已有世界，或直接导出 .mcworld / 电脑世界文件夹。
5. 进游戏放一个盔甲架，用命名牌命名为填写的名称；保持它在当前维度已加载区。不要让画面与盔甲架或控制组重叠。
6. 用输出的“检查盔甲架”命令确认能找到，再执行“播放”命令。没有找到实体时不会安装命令链。
7. 启动时绑定距启动坐标最近的同名盔甲架，后续每个实际播放帧通过该视频专属标签定位。建议每个视频使用唯一的名称；修改名称后可重新播放绑定。
8. 停止与清理仍使用原启动坐标，无需盔甲架还留在原位置。停止拆除命令链，保留画面；清理还移除绑定标签及两个常加载区域，不删除盔甲架或画面。

实体跟随的范围：
这是 execute at + structure load 的方块放置方式，不是把整个屏幕变成可平滑移动的实体。位置向下取整到方块格，朝向由导出选项决定，不跟随盔甲架转身。
移动盔甲架后，下一实际播放帧会在新位置加载完整屏幕；旧位置的画面不会自动擦除。
连续重复帧合并后可能长时间停留，停留期间不额外追踪坐标。若需要更频繁地更新移动位置，可关闭“合并连续重复帧”，但会增加帧结构和控制组负载。
实体模式不跳过静止地图块，否则换位置会缺图。相同内容的地图仍可共用，画面按完整帧加载，负载可能比固定坐标模式高。
启动会为固定控制区与初始屏幕分别申请常加载区域，需要剩余两个名额；屏幕常加载区域不自动跟随实体迁移。
盔甲架移出已加载区、跨维度或被移除时，后续帧无法定位。先清理再迁移控制组；保持画面在世界建筑高度内且位于空地。

旧视频包 / 已安装世界切换模式，无需重新抽帧：
1. 选择原 .mcvideo 与目标世界 .mcworld。
2. 首次加入视频时，处理内容选“加入视频”；在“合并后的画面定位”选固定坐标或命名盔甲架。
3. 已经安装该视频时，先在原启动坐标停止播放并导出世界，处理内容选“优化已安装视频”，再选目标定位方式。锚点名称和偏移也在此修改。
4. 保存并导入世界副本，在原启动坐标执行播放命令。
“沿用视频包／已安装播放器”会优先保留世界中的定位配置，不会被更早的原视频包覆盖。
“修复／补配音”保留地图与帧，只能沿用现有定位；切换模式或改锚点需选择优化入口。
优化保留旧数据库记录，并追加重新引用的地图，世界文件可能增长，不是数据库清理或压缩功能；避免重复优化同一副本。

下载与启动：
安卓：下载“方映-安卓离线版-v13.html”后用浏览器打开。视频在本机处理、不上传；转换时保持前台。
Windows：解压“方映-电脑大音频版-v13.zip”，安装 Python 3，运行“启动电脑版.bat”，用 Chrome / Edge 打开。视频在本机处理，地址仅监听本机。保持启动窗口开启。
内存模式最高 1024 MiB 地图原始数据，实际上限受浏览器可用内存影响。电脑磁盘模式最高 64 GiB，支持 ZIP64 和空世界文件夹输出。
容量按实际独立地图数据计算，结构、音轨和原世界另占空间；请预留完整世界副本空间。超出容量会停止，不会自动截短。
最多保存 16384 个播放帧，连续重复帧合并时最多检测 1000000 个采样帧。竖向控制组最高 128 格，长视频启动底部 Y 不高于 192。
.mcvideo 是自定义视频包，需要在工具里合并世界，不能直接用 Minecraft 打开；.mcworld 才交给游戏导入。实体包用格式 v5，需要 v12 或更新工具；固定坐标仍输出兼容 v1–v4。

画面和音频：
默认无损复用完全相同的地图块。运动、压缩噪点较多的视频可能几乎没有无损节省。
可选“轻度／强省资源”，暂时保留变化较小的旧块，但属于有损处理，可能滞留字幕、小物体或运动细节。
默认从视频提取音轨，也能选独立音频或静音。浏览器需支持音频编码；提取失败可改选独立音频。
音轨保存为 24 kHz 单声道 WAV，通过资源包替换 13 号唱片，并保留每个视频独立声音事件。
开启资源包并调高唱片音量。首帧及每轮循环在画面锚点选取附近 64 格玩家播放声音；停止／清理会停音。移动时不会持续重播声音，中途加入者需等下一轮或重新播放。
音频按实际时间、画面按游戏刻运行，低 TPS 仍可能不同步。

验证：
八组自动检查通过（包含新增音频额度与 WAV 分块检查），覆盖原格式、去重、音频、磁盘与命令复制、新旧模式切换、v5 校验、绑定标签、正负和小数实体坐标、完整结构重建，以及内存/磁盘/直接世界导出。
尚未在 Minecraft 客户端实测实体跟随及其渲染表现。请先备份世界并用副本测试；此功能不保证解决粉屏，也不能强制释放客户端纹理缓存。粉屏后请先完全退出游戏再测试新副本。
