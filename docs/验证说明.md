## Windows v20.6：旧存档追加与一键国际版往返

- 第 05 区域支持选择已有世界，默认保留名称及原 `level.dat` 设置。提供直接追加和“一键往返：中国版解密 → 国际版添加视频 → 加密写回”两种方式。往返使用现有国际版合并核心，随后把帧引用转换为中国版原生命令；复用地图 ID，含盔甲架、音轨及原生预加载。保留并验证原始备份，写回同一路径，目标变化时拒绝覆盖。
- `tests/china-old-world.cjs` 使用官方服务器保存后的多份压缩 SST 表与日志构造隔离样本。保留该样本的实体／会话计数，仅调整版本标签以测试 1.21 加密格式，并加入合成背包、等级和原有地图记录；这不是普通中国版客户端生成的实测旧世界。两条路径逐项比对 688 条原有逻辑记录，保留已有表／日志字节、原名称、版本、其他设置、资源文件及旧播放器。另验证往返地图编号不重复写入、备份、控制区重叠拒绝、打包阶段取消的音轨清理和跨分块 XOR 一致性。
- `python tests/china-engine.py --roundtrip` 在官方 BDS 1.26.30.5 上运行往返结果，只改变测试画面的背板颜色用于观测，关闭应用行为包，仅启用观测脚本。5 个同名盔甲架各自朝向、转向、后加入播放点、异名排除、循环及重播通过；首轮 41 次画面变化、重播 35 次，每帧均 2 游戏刻，顺序错误为 0。未进行听感验证，也不能替代普通中国版 1.21.120 客户端验收。
- 使用真实 Electron 表单、受限 IPC 和 Worker 对旧存档走一键往返、原位备份写回、音轨部署／移除／重试；普通直接追加的导出与取消也保留回归检查。所有测试世界及工具位于 F 盘隔离目录，未改用户的实际旧存档。
- 测试曾发现给旧数据库配新建 `level.dat` 会让原生命令中的实体位置解析与脚本观测不一致。保留原实体计数及会话信息后同一检查通过；产品两条流程均保留原设置，不使用新建世界配置替代旧配置。当前普通中国版的新流程、长视频同步和渲染改善仍需客户端验收。本次未改共享 HTML 或安卓功能。

## Windows v20.5：中国版原生预加载

- 中国版独立入口支持沿用视频包、关闭或自定义 1–200 帧与上方高度。每排 5 幅向上堆叠，按玩家所在 16×16 区块登记，上限 4 处、屏幕原点周围 64 格。原生 AEC 标记、结构及计分板推进，不安装方映行为包。辅助链与主播放链分处相邻区块；使用累计进度追赶环形更新，避免区块执行顺序不同丢帧。不再使用运行时磁盘结构存取来传递画面。
- `tests/china-prefetch-engine.py` 使用官方 BDS 1.26.30.5 验证 205 帧、20 FPS、8×4 屏幕、200 预加载位。观测脚本仅把玩家选择器替为命名盔甲架并采集结果，不提供生产播放逻辑；检查 15.99/16.01 区块边界、迁移清理、同区块共享、跨两轮循环、停止无地图掉落和重新播放。

- 设置 `MAPCINEMA_PREFETCH_NONLOOP=1` 后另跑同一官方服务器测试，再执行 `node tests/china-prefetch-verify.cjs --nonloop`：验证非循环末尾自动清理、无地图掉落、重新播放，以及 2 次快照共 12,800 个地图位置的后续帧／空白尾部。

- BDS 的命令及数据通过，不代表普通中国版 1.21.120 的纹理渲染通过。当前中国版预加载墙外观、实际缺图改善、200 帧负载与流畅度仍需普通客户端验收；额外刷新可能增加卡顿。本次仅改 Windows 中国版入口，不改共享 HTML 或安卓版本。

## Windows v20.2.1：临时目录与重启提示

- 实际问题定位：用户本次 132.8 秒 WAV 音轨完整且非静音，部署的 5 个资源文件与世界内副本一致；但客户端进程启动早于音轨登记，方映从压缩软件 C 盘临时解压目录运行，全局音轨链接也指向该临时目录。保留音轨到 F 盘并在普通客户端正常退出后修正对应链接，不修改世界数据库或视频内容；用户重新启动普通客户端、执行该视频专属的声音检测命令后，确认已听到视频自身的音频。此结果确认该次视频音轨可加载，尚不能扩大为全程音画同步通过。

- tests/reverse-smoke.cjs 验证视频包、原始日志世界、合成 SST 和官方引擎整理世界的 H.264/AAC、离线 AAC 备用编码、直接保存、内存下载、无声输出与取消恢复。
- tests/verify-reverse.py 用独立 FFprobe／FFmpeg 完整解码，检查帧数、分辨率、帧率、色块拼接和重复帧停留时间，确认音轨可解码且非静音。
- 本机完整旧世界只读恢复了 1024×512、20 FPS、1917 帧、视频轨 95.85 秒，输出约 23.9 MB；独立探测和完整音视频解码通过。该世界与视频未上传。

AAC 以 1024 采样帧编码，容器／音轨时长可能含少量头尾填充。长样例的视频轨为 95.85 秒，FFprobe 显示容器时长约 95.915 秒；这不等同于视频帧被延长。未做听感验收，也未在 Android 真机上安装或编码。
