# v16.1 验证说明

发布整理保留了 v16.1 的转换与播放 HTML，改动集中在独立构建工具链、包描述及发布文档。构建工具固定为 Electron 44.9.0 与 rcedit 5.0.2，构建时校验工具文件的 SHA-256。

- 播放逻辑检查覆盖 1–16,384 帧的边界、可变帧时长、循环、非循环末帧保留和周期完整刷新。
- 旧世界升级检查覆盖原地图引用、时序、数据库和音轨保留，以及缺帧拒绝、取消和重复升级。
- 多盔甲架检查覆盖同名选择、独立水平朝向、角度边界、新播放点、转向更新和音频去重。
- 实际打包 EXE 检查覆盖视频解码、PCM 音频、磁盘及内存导出、世界合并、无原视频包升级和盔甲架输出。
- 发布便携包检查覆盖 ZIP CRC、全部构建清单文件 SHA-256、源码与包内 HTML 一致性，以及测试导出音轨与函数。

此前已使用官方 Bedrock Dedicated Server 1.26.30.5 复现未加引号的 `#` 记分板名称造成的函数加载失败，并验证修复后函数加载、等待计数和首帧推进。还在已加载区块内，通过三帧非循环短样例验证了独立脉冲命令方块两次通电、两次播放结束。

上述官方引擎检查针对与本仓库相同的 v16.1 播放生成代码，不包含 Minecraft 客户端中的完整长视频画面、流畅度或音画同步验收。不同版本和设备仍需实际测试。

本机验证使用过的个人长视频世界、个人路径及原始日志不随仓库发布。重新运行源码测试所需的小型夹具位于 `tests/fixtures/`。
